How it works

Gamified learning

Planeteers is a hybrid game, consisting of a physical game kit, and a digital app which does the game facilitation and scoring. Designed to help primary school teachers, it helps to introduce sustainability in a way children love. The game aims to spark competition, collaboration and cooperation through discussion and teamwork.

🛝

Age-appropriate

The game is designed for children aged 7-12, with simple mechanics and engaging visuals.

 

When children explore trade-offs between cost, health, and the environment through guided gameplay, complex topics like sustainability become tangible and surprisingly intuitive.

💬

Teacher-led discussions

The teacher guides the discussion and connects the game to what their class is already learning.

 

Only the teacher operates the screen: one big screen for the teacher to be in control and no small screens for each student.

🧩

Modular & Adaptable

Designed for different cultures, languages, and curricula.

 

We bring the game first to Switzerland and make it compatible with the Swiss curriculum (Lehrplan 21).

 

We will bring the game all around the world, always adapting to local needs and contexts.

For teachers

Play the game

Hello teachers, we are so thrilled that you are with us! If you hold the game kit in your hand, this message is for you...

 

Game rules can be overwhelming. That's why we made a digital game facilitator ↗️. You control the game flow, each step expains itself on the screen. The scoring is done automatically for you. You can focus on the kids in the class.

 

Still prefer the fully offline gameplay? We have you covered. Download the offline game rules here: Planeteers game rules (English) ↗️

  • 📦 Game kit: Everything a teacher needs is one small box with the game cards and an account with access to the digital facilitator. The game can be also played fully offline.
  • 🌎 Culturally adaptable: Tested across India and Switzerland. Scenarios and language can be localised for any market.
  • 🛡️ Privacy-focused: Designed for maximum privacy, the digital component of the game collects no student data, requires an account only for the teacher, puts the educator in full control of all stored information, and we store all data securely, and locally (for Switzerland: in Swiss data centers).
  • 🎴 Expansion packs: New scenarios keep the game fresh across the school years.
